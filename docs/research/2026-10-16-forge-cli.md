# Forge CLI

- **Question:** fj isn't the 1:1 with gh it looked like. Is there a better CLI for the forge than fj and tea, with one tool covering both Vex and Shane?
- **Researched:** 2026-10-16, normal

The forge runs Forgejo 15.0.9 (`GET /api/v1/version`, 2026-10-16). caboodle
sets no `services.forgejo.package`, so it takes the NixOS module's default.

## Sub-questions

1. tea against Forgejo: SSH-alias remotes, PRs, reviewers, Actions logs, multiple logins, maintenance, nixpkgs: answered
2. fj after 0.6.0: fixes for the alias order, reviewers, Actions logs, `--repo`; maintenance: answered
3. Other contenders (berg, gh-style CLIs, MCP servers): answered
4. What the Forgejo API exposes for reviewers, Actions logs and PR checks, and since which version: answered

## Claims

Each claim, then its source, date and verdict.

- Latest tea release is v0.16.0; nixpkgs ships it.
  https://gitea.com/api/v1/repos/gitea/tea/releases/latest, https://raw.githubusercontent.com/NixOS/nixpkgs/master/pkgs/by-name/te/tea/package.nix (2026-09-10): confirmed.
- tea 1.0 (Cobra rebuild, noun-verb commands, `tea auth login`) is on main, untagged, and requires Gitea 28+ with no version probing.
  https://gitea.com/gitea/tea/raw/branch/main/docs/migration-1.0.md (2026-10-12): confirmed for main, not released.
- tea matches an scp-style remote to a login by exact `ssh_host`, never reading `~/.ssh/config`; same in v0.16.0.
  https://gitea.com/gitea/tea/raw/tag/v0.16.0/modules/context/context_remote.go (2026-09-10): confirmed; locally `tea pr list` in caboodle resolves via `ssh_host: forge`.
- tea selects among several logins with `--login`/`--host`/`--user`, env vars, or `tea auth switch` (1.0).
  https://gitea.com/gitea/tea/raw/branch/main/internal/app/target.go (2026-10-12): confirmed for main, v0.16.0 not checked.
- tea v0.16.0 requests reviewers with `tea pr edit --add-reviewers`.
  local `tea pr edit --help`, v0.16.0 (2026-09-10): confirmed.
- tea v0.16.0 has `tea actions runs list/view/logs/cancel`.
  local `tea actions runs --help`, v0.16.0 (2026-09-10): confirmed.
- `tea run rerun --failed` calls a route no Forgejo version has.
  https://gitea.com/gitea/go-sdk/raw/branch/main/actions_run_jobs.go (2026-10-15): contradicted by Forgejo v15-v17 route tables.
- tea's CI tests only against Gitea 28 and its source never mentions Forgejo.
  https://gitea.com/gitea/tea/raw/branch/main/.gitea/workflows/test-pr.yml (2026-10-12): confirmed.
- Forgejo and Gitea are separate codebases; Forgejo reports Gitea 1.22 compatibility.
  https://forgejo.org/2024-12-gitea-compatibility (2024-12-18): confirmed as policy; tea-on-Forgejo compatibility unconfirmed.
- tea maintenance: tags v0.15.0, v0.15.1, v0.16.0 between July and September 2026; commits to 2026-10-12.
  https://gitea.com/api/v1/repos/gitea/tea/tags (2026-10-12): confirmed.
- Latest fj release is v0.6.0; main is at 0.7.0, unreleased; nixpkgs ships 0.6.0.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli/tags (2026-07-19): confirmed.
- fj moved to codeberg.org/forgejo-contrib/forgejo-cli.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli (2026-10-16): superseded the Cyborus/forgejo-cli URL.
- fj v0.6.0 added SSH config HostName resolution (!462), applied before alias lookup, unchanged on main.
  https://codeberg.org/forgejo-contrib/forgejo-cli/raw/branch/main/src/main.rs (2026-10-16): confirmed by source; caboodle works around it in the fj wrapper.
- fj reviewer requests (`fj pr review <id> request`) merged as #730, unreleased.
  https://codeberg.org/forgejo-contrib/forgejo-cli/pulls/730 (2026-10-16): confirmed, unreleased.
- fj has no Actions run or log command; feature request #669 is open.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli/issues/669 (2026-09-23): confirmed.
- fj stores one login per host.
  https://codeberg.org/forgejo-contrib/forgejo-cli/raw/branch/main/src/keys.rs (2026-10-16): confirmed.
- fj `--repo` handling unchanged; PR #612 only tidies short flags.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli/pulls/612 (2026-07-24): unconfirmed, no full audit.
- fj issue #444 (`FORGEJO_HOST` env var) is still open.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli/issues/444 (2026-05-01): confirmed.
- fj is maintained: 110 commits since v0.6.0, latest 2026-10-16.
  https://codeberg.org/api/v1/repos/forgejo-contrib/forgejo-cli/compare/v0.6.0...main (2026-10-16): confirmed.
- berg (Aviac/codeberg-cli) is archived and points to fj.
  https://codeberg.org/Aviac/codeberg-cli/raw/branch/main/README.md (2026-03-18): superseded by fj.
- fgh is a single-file Bash gh-style CLI with reviewers, checks and Actions logs, configured by `FORGEJO_URL`; no releases; not in nixpkgs.
  https://github.com/djdembeck/forgejo-cli/blob/main/README.md (2026-09-04): confirmed from README, not run.
- fgj is a Go gh-style CLI with per-host logins, `pr edit --add-reviewer` and Actions logs, but no review submission; not in nixpkgs.
  https://codeberg.org/romaintb/fgj/raw/branch/main/README.md (2026-09-30): confirmed from README, not run.
- fgj infers the host from the origin remote.
  same README (2026-09-30): unconfirmed.
- cb (thatxliner/codeberg-cli) is Python, one instance at a time, no documented reviewer requests or logs; not in nixpkgs.
  https://codeberg.org/thatxliner/codeberg-cli/raw/branch/main/README.md (2026-06-14): confirmed.
- SquareCows forgejo-mcp exposes reviewer requests and Actions job logs, one instance per server.
  https://code.squarecows.com/SquareCows/forgejo-mcp/raw/branch/main/README.md (2026-10-15): confirmed from README.
- b4mad forgejo-mcp covers review requests and Actions logs for Forgejo v16+; in nixpkgs as `forgejo-mcp` 3.2.0.
  https://codeberg.org/goern/forgejo-mcp (undated): unconfirmed, mirror only.
- gitea-mcp covers reviewers and Actions logs but targets Gitea; nixpkgs `gitea-mcp-server` 1.8.0.
  https://gitea.com/gitea/gitea-mcp/raw/branch/main/README.md (2026-10-09): unconfirmed for Forgejo.
- Kunde21 and raohwork forgejo-mcp lack reviewers and logs and are stale.
  https://raw.githubusercontent.com/Kunde21/forgejo-mcp/master/README.md, https://github.com/raohwork/forgejo-mcp/blob/master/README.md (2025-10-28): confirmed.
- Forgejo API has `POST /repos/{owner}/{repo}/pulls/{index}/requested_reviewers` in v11 through v17.
  https://codeberg.org/forgejo/forgejo/raw/branch/v11.0/forgejo/templates/swagger/v1_json.tmpl (2025-04-16): confirmed.
- Commit status endpoints exist v11 through v17; there's no PR-level checks endpoint, so checks come from the head SHA.
  same spec (2025-04-16): confirmed.
- Actions runs list/get arrive in v12; run jobs, job logs, run logs, cancel and artifacts in v16.
  https://codeberg.org/forgejo/forgejo/raw/branch/v16.0/forgejo/templates/swagger/v1_json.tmpl, https://forgejo.org/2026-07-release-v16-0 (2026-07-16): confirmed.
- Single-job get, step-filtered logs and rerun arrive in v17.
  https://forgejo.org/2026-10-release-v17-0 (2026-10-15): confirmed.
- Forgejo v16 support ends 2026-10-29.
  https://forgejo.org/releases/ (2026-10-12): confirmed.
- nixpkgs ships Forgejo 16.0.6.
  `nix eval nixpkgs#forgejo` (2026-10-16): confirmed.

## Gaps

- No CLI was run against a Forgejo 16+ instance, so log commands are untested here; on 15.0.9 they can't work.
- tea v0.16.0's multi-login flags weren't checked against its source, only main's.
- Whether tea 1.0's Gitea 28 floor breaks against Forgejo is unknown until it's tagged.
- b4mad forgejo-mcp's canonical site is behind a bot check, so its release date is unverified.
- fgh and fgj host handling comes from their READMEs.
